    What this page can and cannot do
    
        
    
        
    
          
    
            This page can monitor public GitHub issue state directly from the browser, generate the
            local queue startup command, and export a config file matching the watcher format.
          
    
          
    
            It cannot launch local watcher processes by itself from the browser. Use the generated
            command on the machine where your queue automation scripts live.
